## 3. 必过集合（Blocking E2E）

`tests/e2e/acceptance.spec.ts` 中全部 15 条用例均为必过集合，必须 100% 通过：

- E2E-001 ~ E2E-010
- E2E-011（题目含多解法时必须通过；单解法时该用例会自检并跳过多解法分支）
- E2E-012 ~ E2E-015

## 4. 执行阈值

- 执行环境：Chromium，视口 1920x1080。
- 首次执行先运行 `npm run test:e2e:install`。
- 核心链路默认不重试；仅 flaky 场景允许最多 2 次重跑并留痕。
- 最终结论规则：
  - 15 条 E2E 任一失败 => AC-017 = FAIL => 总结论 FAIL
  - 15 条 E2E 全通过，且 AC-001~AC-024 都 PASS => 总结论 PASS
