# 视觉布局与空间分配规范

> 目标：单屏之内，**画布是主角**，标题、输入、页签、控制栏只是配角和操作入口。
> 任何“为了好看”而加的外层留白，只要挤占了画布，都视为缺陷。
> 量化门槛由 `qa:guard` 与 E2E-001 强制执行，不能只靠主观判断。

---

## 1. 三条硬原则

1. **画布优先（canvas-first）**：先给画布分空间，再给其它区域分剩余空间；不是先排完标题和边距再“剩下的给画布”。
2. **单行收口**：标题、输入、页签、控制栏都必须单行完成，不允许换行撑高；长文本用省略号或 tooltip，不靠增加高度解决。
3. **留白服务于分组**：留白只用来区分层级，不能形成无信息的空白带。页面外层不允许出现 20px 以上的连续留白。

---

## 2. 空间预算（Blocking）

以 `1366×768` 和 `1920×1080` 两档为基线，实测值必须满足：

| 区域 | 1920×1080 | 1366×768 | 规则 |
| --- | --- | --- | --- |
| 顶部标题栏 | 44px | 44px | 固定 44–52px，只放一行标题 + 左右操作 |
| 输入条 | ≤ 44px | ≤ 44px | 单行；内边距 6px 12px |
| 解法页签 | ≤ 32px | ≤ 32px | 内边距 4px 12px；无解法时不占行 |
| 控制栏 | ≤ 56px | ≤ 56px | 按钮 / 进度条 / 步数压成一行 |
| 非画布区域合计 | ≤ 22% 视口高 | ≤ 26% 视口高 | header + 输入 + 页签 + 控制栏 |
| 画布卡片高度 | ≥ 76% 视口高 | ≥ 62% 视口高 | `.canvas-card`（含教学层） |
| 实际绘图区高度 | ≥ 66% 视口高 | ≥ 50% 视口高 | `.viz-canvas`（`canvas-svg`） |
| 画布宽度占比 | ≥ 70% | ≥ 68% | 画布 : 代码栏 ≥ 2.2 : 1 |
| 代码面板宽度 | 360–400px | 320–360px | `clamp(320px, 24vw, 400px)` |

计算口径（E2E-001 使用同一公式）：

```text
chromeRatio     = (header + input + tabs + footer) / innerHeight
canvasHeightRatio = canvasCard.height / innerHeight
svgHeightRatio   = canvasSvg.height / innerHeight
canvasWidthShare = canvasCard.width / (canvasCard.width + codePanel.width)
```

阈值允许 1–2px 取整误差；超出即 FAIL。

## 3. 间距系统

### 3.1 只允许 4 的倍数

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
```

- 页面级 padding：8px（工作区）/ 12px（横向栏）。
- 相邻功能栏：`gap: 0` 或 8px；栏与栏之间用 1px 分隔线，不用空白。
- 卡片内部 padding：5–10px；教学层更紧凑。
- **禁止**：外层 `padding: 20px/24px/32px`，`gap: 24px/32px`，`margin-top: 24px` 等“大呼吸感”写法。
- **禁止**：标题栏下面再加一条副标题/说明栏；需要说明就放进画布解说或弹窗。

### 3.2 模板实测结构

```text
header        44px  padding 0 12px
input bar     42px  padding 6px 12px
tabs          30px  padding 4px 12px
workspace     flex  padding 8px, gap 8px
footer        48px  padding 5px 12px
canvas card   title 24px / caption ≤34px / meta 20px / echo 15px
```

除画布卡片内部的 info 区外，任何区域的纵向内边距不得超过 12px。

---

## 4. 顶部标题

- 高度 44–52px，**单行**；`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`。
- 字号 16px、字重 700；不要再叠加 20px+ 的大标题、英文副标题、作者信息、版本号。
- 标题居中，左侧 Hot 100 返回、右侧思路按钮 + GitHub 徽标用绝对定位放在同一行；不要另起一行放工具按钮。
- 标题可用宽度 = 容器宽度 − 左右操作区，`max-width: calc(100% - 300px)`；长标题省略而不是换行。
- 禁止 banner/hero 式头部（大留白 + 大字 + 副标题），页面顶部不是宣传页。

反例：

```css
.problem-header { min-height: 96px; padding: 24px 32px; }
.problem-title  { font-size: 28px; line-height: 1.6; }
```

正例：

```css
.problem-header { min-height: 44px; padding: 0 12px; }
.problem-title  { font-size: 16px; line-height: 1.2; white-space: nowrap; }
```

---

## 5. 画布与代码栏的主次

- 工作区使用 `grid-template-columns: minmax(0, 1fr) clamp(320px, 24vw, 400px)`。
- 画布必须拿到剩余宽度；代码栏不得用 `minmax(420px, 1fr)` 之类把画布挤到 60% 以下。
- 画布卡片 `height: 100%`，`min-height: 0`；代码面板同样 `height: 100%`，内容区独立滚动。
- 1366 宽以下仍保持左右分栏；只有 `< 1100px` 才允许代码栏下移，并且高度限制在 180–240px。
- 不允许给画布设置固定像素高度（如 `height: 520px`），否则大屏浪费、小屏溢出。

---

## 6. 画布内部空间

### 6.1 绘图区必须铺满

- SVG 使用 `width/height: 100%` + `viewBox` 自适应。
- 逻辑画布基准 `1200×720`；当容器比例不同，按容器比例扩展 `viewBox`，**不能留下左右或上下黑边**。
- 内容（节点、容器、主结构）应占据可用区域的 **≥60% 宽、≥50% 高**，整体居中；典型边距 40–80 逻辑像素。
- 禁止把所有节点挤在左上角或只占画布中央一小块；辅助结构（栈/队列/哈希）放在主结构右侧或下方，间距 40–80px。

### 6.2 教学层占用上限

| 区域 | 高度上限 | 字号 |
| --- | --- | --- |
| 画布标题（解法 + Step） | 24–30px | 12px |
| 操作徽标 | 20px | 10px |
| 解说 caption | 34px（最多 2 行） | 12px |
| 图例 / 指标行 | 20–24px | 10–11px |
| 输入回显 | 16px（单行省略） | 10px |

教学层总和不超过画布卡片高度的 15%；操作徽标、解说、图例不能为了“显眼”放大到 14–16px。

---

## 7. 字体与视觉层级

| 层级 | 字号 | 用途 |
| --- | --- | --- |
| 页面标题 | 16px / 700 | 题号 + 中文标题 |
| 区块标题 | 12–13px / 600 | 画布标题、代码语言 |
| 正文 | 12px | 解说、输入、变量 |
| 辅助信息 | 10–11px | 图例、指标、快捷键、回显 |
| 画布节点 | 11–12px / 600 | 节点值；注释 9–10px |

- 同屏字号不超过 5 档；不使用 14px 以上的正文/工具文字。
- 边框统一 1px，圆角 8–10px；阴影只用于浮层，不用于常规卡片。
- 强调只靠颜色 + 字重 + 状态光晕，不靠加大字号和留白。

---

## 8. 响应式规则

| 视口宽度 | 布局 |
| --- | --- |
| ≥ 1100px | 画布左、代码右；代码栏 320–400px |
| 900–1099px | 代码栏移到画布下方，高度 `clamp(180px, 22vh, 240px)` |
| < 900px | 控制栏可换行；画布仍保持首屏主体，页面不得出现纵向滚动 |

- 任何断点下都必须保持单屏，不允许因为换行产生滚动。
- 1080p 与 1366×768 是必测档位；有条件的再加 1440×900。
- 缩放浏览器到 125% 时，关键区域仍应可见；不允许靠 `overflow: hidden` 掩盖被裁掉的内容。

---

## 9. 自检清单

- [ ] 顶部栏 ≤ 52px，标题单行，没有副标题行或工具行。
- [ ] 外层没有 20px 以上的 padding/gap；功能栏之间用分隔线而不是空白。
- [ ] 控制栏是一行，不是按钮一行 + 进度条一行 + 步数一行。
- [ ] 画布卡片 ≥ 62% 视口高（1366×768），SVG ≥ 50% 视口高。
- [ ] 画布宽度 ≥ 68%，代码栏 ≤ 400px。
- [ ] SVG 无黑边，内容占据画布主体，不缩在角落。
- [ ] 教学层总高 ≤ 画布卡片 15%，解说最多 2 行。
- [ ] 1100px 以下代码栏下移且不超过 240px，页面仍无纵向滚动。
- [ ] E2E-001 在 1920×1080 与 1366×768 均通过。

## 10. 常见错误对照

| 错误写法 | 后果 | 正确做法 |
| --- | --- | --- |
| 顶部 `min-height: 80px` + 28px 标题 | 画布少 40px，视觉重心跑到标题 | 44px 单行 + 16px 标题 |
| `.workspace { padding: 24px; gap: 24px; }` | 四面各吃 24px，画布明显缩小 | `padding: 8px; gap: 8px` |
| 控制栏三行 | 底部吃掉 100px+ | 按钮/进度条/步数一行 |
| 代码栏固定 420px | 1366 屏画布只剩 65% | `clamp(320px, 24vw, 400px)` |
| SVG 固定 viewBox + 容器留黑边 | 视觉上画布没铺满 | 按容器比例扩展 viewBox |
| 画布标题 16px + 解说 16px + 图例 14px | 教学层喧宾夺主 | 12px/12px/10px |
| 用大留白营造“高级感” | 信息密度低，画布变小 | 用分组线、底色、字重建立层级 |
