# 动画规格说明（ANIMATION_SPEC）

> 对应验收项：AC-023（动效语法与教学层完整）。
> 本文件在实现画布前填写，验收时逐条核对。
> 方法论见 Skill 内置的《动画与运动设计规范》（`references/08-animation-motion-design.md`）。

## 1. 本题结构与焦点

| 项目 | 内容 |
| --- | --- |
| 主数据结构 | 例如：数组 / 链表 / 树 / 图 / 网格 |
| 辅助结构 | 例如：哈希表 / 栈 / 队列 / 递归栈 |
| 必须画出的标量 | 例如：`i`、`j`、`ans`、`sum` |
| 每步焦点上限 | 1 个 `current`，最多 2 个 `compare` |
| 步骤总数 | 例如：12 步（超过 40 步必须先合并） |

## 2. 步骤规划表

| step | operation | 焦点元素 | 状态变化 | 解说要点 | 代码锚点 |
| --- | --- | --- | --- | --- | --- |
| 0 | init | — | 创建结构 | 初始化哪些值、为什么 | init |
| 1 | read | 元素 A | A: idle → current | 读到了什么、影响哪个变量 | loop |
| 2 | compare | A, B | A/B: current → compare | 比较依据与结果 | loop |
| 3 | move | 指针 | A: current → visited | 为什么移动、移动到哪里 | loop |
| 4 | return | 结果 | 结果: current → done | 返回什么、为什么正确 | return |

要求：

- 每行只允许一个语义动作（`operation`）。
- 相邻步骤至少 60% 的元素位置保持不变（稳定布局）。
- 焦点离开后转 `visited`，不得直接恢复 `idle`。

## 3. 运动语法

| 变化 | 实现 | 时长（1x） | 缓动 |
| --- | --- | --- | --- |
| 入场 | 0.6 倍缩放 + 淡入 | 220ms | easeBackOut |
| 移动 | `transform` 平移 | 360ms | easeCubicOut |
| 状态切换 | CSS 颜色过渡 | 240ms | ease |
| 退场 | 淡出后由 `fadeOutAndRemove` 移除 | 180ms | easeCubicIn |
| 箭头 | `pathLength=1` + dash offset 生长 | 420ms | easeCubicOut |

时间 token 统一来自 `features/animation/motion.ts` 的 `MOTION`，禁止在各个组件里散落魔法数字。

## 4. 状态图例

| 状态 | 含义 | 本题是否使用 |
| --- | --- | --- |
| `current` | 当前焦点 | 是 |
| `compare` | 正在比较 | 是/否 |
| `visited` | 已访问/已排除 | 是/否 |
| `done` | 已确认结果 | 是 |
| `path` | 最终路径 | 是/否 |
| `error` | 冲突/剪枝 | 是/否 |

- 图例固定在画布内，所有步骤共用同一组，顺序不变。
- 颜色不是唯一信号：`current` 有光晕，`done`/`path` 加粗描边。
- 禁止紫色系；同屏高饱和色不超过 3 种。

## 5. 辅助结构容器（栈 / 队列）

本题是否使用栈/队列：是 / 否（使用则必须逐项填写）

| 项目 | 内容 |
| --- | --- |
| 容器类型 | 栈 / 队列 / 递归栈 |
| 固定容量 | 例如 5（≥ 4，槽位不随元素数量变化） |
| 元素顺序 | 栈：栈底→栈顶；队列：队首→队尾 |
| 指针 | 栈顶/栈底；队列队首/队尾（空队列不画；队首指首个占用槽位，队尾指下一个入队槽位，满队指最后槽位） |
| 空状态文案 | 例如“空栈 / 空队列” |
| 入/出方向 | 从哪个方向飞入/飞出，对应哪条箭头文字 |
| 布局 API | `createStack` / `createQueue`（`features/animation/structures.ts`） |

要求：

- 必须画出外框、槽位、标题、占用计数 `n/capacity` 与方向指针。
- 出栈/出队后其余元素的 ID 不变，位置平移补位。
- 禁止只用一排裸节点或纯文字表示栈/队列。

## 6. 箭头与标注规范

| 项目 | 规则 |
| --- | --- |
| 箭头文字 | 每条箭头必须有 `text`（动作 + 对象）或明确的 `kind: 'pointer'` |
| 箭头走向 | 重叠时用 `curve` 让开；`labelPosition` 控制文字落点 |
| 标注文字 | `text` 说明是什么，`detail` 说明下一步/原因 |
| 标注位置 | 按标签尺寸 + 节点半径 + 14px 间距计算；用 `placeLabels` 做避让，不写死偏移 |
| 碰撞处理 | 首选 `position` 冲突时依次尝试 `top→bottom→left→right`；全部冲突取重叠面积最小 |
| 边界钳制 | 标签框保持在逻辑画布 1200×720 的安全区内（边距 8px） |
| 引导线 | `variant: 'pointer'` 时画，从标签框边缘连到节点外沿，不得穿过节点或其它文字 |
| 节点文字 | 用 `fitNodeLabel` 缩小（12→9px）/截断，完整文字写入 `<title>` + `aria-label` |
| 层级 | 容器 < 边 < 箭头 < 节点 < 标签 |

## 7. 布局、空间预算与坐标

**画布优先**：1366×768 下 header + 输入 + 页签 + 控制栏 ≤26% 视口高，画布卡片 ≥62%、SVG 绘图区 ≥50%；1920×1080 下分别为 22% / 76% / 66%。顶部栏 44–52px、标题单行 16px；页面外层间距只用 4/8/12/16px；控制栏单行（按钮组 | 进度条 | 步数）；代码栏 320–400px。详见 `references/09-layout-visual-design.md`。

- 逻辑画布：`1200 × 720`，按容器比例扩展 `viewBox`，不得出现黑边。
- 主结构坐标规则：`x = ...`，`y = ...`（写清公式），内容占绘图区 ≥60% 宽、≥50% 高。
- 辅助结构泳道位置：右侧 / 底部，与主结构间距 40–80px。
- 节点最小间距：`2 × radius + 16`。
- 稳定 ID 规则：例如 `a0..a n-1`、`node-{value}`、`frame-{depth}`。
- 镜头策略：默认全览；仅在结构超出视口时跟随；用户手动缩放后本次播放不再自动移动。

## 8. 教学层

- 步骤标题：`Step N / 总数：标题`
- 操作徽标：由 `step.operation` 渲染。
- 解说：`narration` 使用“动作 + 对象 + 原因/结果”，1–2 句。
- 指标：`frame.metrics` 提供 2–3 个（已访问、当前索引、累计值等）。
- 代码同步：每步至少绑定一个 `anchorIds`；变量旁注只展示 2–4 个关键变量。
- 图例与指标必须来自当前快照，不能按动画进度临时计算。

## 9. 无障碍

- `prefers-reduced-motion: reduce` 时 JS 过渡时长归零，CSS 过渡关闭。
- 关闭动画后状态、解说、图例、代码高亮仍完整更新。
- 节点文字与背景对比度满足可读性；不仅靠颜色区分状态。

## 10. 验收清单

- [ ] 相邻步骤位置稳定，无整屏重绘闪烁。
- [ ] 每步只有一个焦点，旧焦点转 `visited`。
- [ ] 每步有 `operation` 徽标与独立解说。
- [ ] 图例始终可见且跨步骤稳定。
- [ ] 代码高亮、变量旁注、画布、解说四者同步。
- [ ] 1x 完整播放节奏可读；3x 播放过渡不排队、不闪回。
- [ ] 随机跳步 10 次、快速切换解法 3 次，画面与目标步骤一致且无残留元素。
- [ ] reduced motion 下信息完整。
- [ ] 无紫色、无重叠、无箭头穿过节点中心。
- [ ] 栈/队列的槽位、计数、指针、空状态逐帧正确。
- [ ] 每条箭头有语义文字，每个标注都能解释“是什么/下一步”。
