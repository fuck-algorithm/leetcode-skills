# Playwright 用例清单（E2E-ID）

> 执行基线：Chromium + 1920×1080（E2E-001 额外测 1366×768）+ `trace: retain-on-failure`
> 运行命令：`npm run test:e2e`（首次执行先运行 `npm run test:e2e:install`）

## 必过集合（Blocking E2E）

`tests/e2e/acceptance.spec.ts` 中的全部 15 条用例均为必过集合，必须 100% 通过：

- E2E-001 首屏单屏布局、空间预算与关键元素可见（1920×1080 + 1366×768）
- E2E-002 顶部三类外链新标签行为
- E2E-003 输入合法性（非法不重算、合法重算）
- E2E-004 样例与随机输入可用
- E2E-005 语言切换与刷新记忆
- E2E-006 代码高亮、变量旁注、解说与画布焦点随步骤变化
- E2E-007 快捷键 Left/Right/Space/R
- E2E-008 进度条拖拽跳步
- E2E-009 画布缩放与平移
- E2E-010 算法思路弹窗开关
- E2E-011 多解法切换隔离（有多解法时）
- E2E-012 交流群浮层与二维码比例
- E2E-013 速度偏好刷新后保留
- E2E-014 GitHub 徽标与 Star 数展示
- E2E-015 无紫色主题 token

## 题目适配规则

- 通用用例不得写死某道题的样例值、变量名或输入结构。
- 题目专属断言（例如两数之和必须返回下标）请**新增**用例，不要删除或弱化通用用例。
- 每种解法至少补充 1 条题目专属 E2E 或单元测试断言，覆盖“输入 → 步骤 → 关键状态”的正确性。

## 建议输出
